# Portal Crane Simulator 🏗️

3D-симулятор портального крана, разработанный в рамках проекта «Инно-Тех». 
Игроку необходимо выполнять логистические задачи: погрузку/выгрузку судов, перемещение контейнеров и снятие крышек палубного судна.

## 🛠 Мой вклад в проект (Роль: Unity Developer)

В рамках работы над проектом реализованы следующие задачи:

1. **Логика крана**: Создал логику движения узлов крана, синхронизированную с системой анимаций.
2. **Механика груза**: Реализовал механику захвата, фиксации и транспортировки груза на крюке между объектами.
3. **Интерфейс (UI)**: Спроектировал и сверстал интерфейс проекта с нуля с использованием **UI Toolkit** (UXML/USS).
4. **Аудио**: Настроил звуковое окружение — интеграция аудиоэффектов для каждой подвижной части крана и фоновых звуков мини-порта.

## 🏆 Ключевые результаты и технологии

* **Физика и взаимодействие**: Успешно разработал стабильную механику подъёма и удержания груза через связку `Joint` и `Rigidbody`. Реализована система триггеров для определения правильной зоны сброса.
* **Современный UI**: Интерфейс полностью реализован на UI Toolkit (включая меню, карточки задач и внутриигровые подсказки).
* **Геймплейный цикл**: Реализована система уровней и проверка выполнения условий задачи (например, снять крышку или разгрузить судно).
